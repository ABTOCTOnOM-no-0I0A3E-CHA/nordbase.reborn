# Nordbase — редизайн сайта: бриф на реализацию

Пакет для передачи в Claude Code. Внутри — готовый статический прототип и всё,
что нужно, чтобы перенести его в боевой проект (сайт на Next.js).

## Файлы

| Файл | Что это |
|---|---|
| `concept.html` | Полный прототип одной страницей. Самодостаточный: CSS, JS и фото (base64) внутри. Открывается двойным кликом. |
| `images/*.jpg` | Те же 4 фото отдельными файлами (вырезаны из текущего сайта, низкое разрешение — заменить на оригиналы). |
| `nordbase_KP.docx` | Коммерческое предложение по автоматизации: варианты и поэтапный план. |

## Что нужно сделать

Перенести прототип в существующий Next.js-проект как набор компонентов, заменить
временные фото на оригиналы, подключить реальную отправку заявки в Telegram.
Прототип — источник правды по вёрстке и стилю; копировать разметку один-в-один
не нужно, важнее сохранить дизайн-систему и структуру.

## Дизайн-система

Шрифты (Google Fonts): `Golos Text` 400/500/600/700 — весь текст;
`Unbounded` 400/600 — только логотип, надписи-эйбрау и мелкие метки.

```
--bg      #07111A   основной фон
--bg-2    #0B1B26   фон чередующихся секций
--bg-3    #102532   карточки
--ink     #EDF6F7   основной текст
--ink-2   #9FBAC6   вторичный текст
--ink-3   #6E8B99   подписи
--line    rgba(197,226,235,.14)   границы
--line-2  rgba(197,226,235,.28)   активные границы
--aurora  #4FD8A6   основной акцент (кнопки, ссылки)
--ice     #69C6E8   второй акцент (цифры, метки)
--violet  #9182EC   третий акцент (зима)
--amber   #F2A94B   тёплый акцент (осень, «занято»)
```

Правила: тёмная тема одна, светлой версии нет. Радиусы 14–18px у карточек,
100px у кнопок. Секции чередуют `--bg` и `--bg-2`. Никаких градиентных кнопок и
свечений — только плоская заливка. Фото всегда под тёмной подложкой-градиентом.

## Структура страницы

1. **Хиро** — фото на всю ширину, заголовок, 3 карточки-направления
   (Северное сияние / Рыбачий / Териберка), как на текущем сайте.
2. **Рыбачий** — рассказ о базе + фото + плашка.
3. **Домики и инфраструктура** — 3 домика (третьего сейчас нет на сайте) +
   4 плитки: душ и туалет, баня, питание, заброска.
4. **Туры по Рыбачьему** — двухдневный и трёхдневный с программой по дням.
5. **Териберка** — 4 сезона + блок «Что сюда привлекает» (6 пунктов).
6. **Транспорт** — вездеход, вместимость.
7. **Заявка** — умная форма + превью карточки в Telegram + календарь занятости.
8. **Цены** — 3 карточки с цифрами + строки без цен.
9. **Вопросы** — аккордеон.
10. **Контакты** — мессенджеры + виджет Яндекс.Карт.

- фото вездехода и заброски (на текущем сайте есть, нужны оригиналы)

## Автоматизация заявки

Форма собирает: направление/тур, даты заезда и выезда, домик, число гостей,
питание, баня, имя, телефон, комментарий.

В прототипе отправки нет — только превью. В боевой версии:

```
POST /api/request  →  Telegram Bot API sendMessage
env: TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID
```

Сообщение владельцу — той же структурой, что в превью прототипа: каждое поле
отдельной строкой, чтобы заявку не приходилось расшифровывать. Гостю — автоответ
«получили, скоро свяжемся». Дальше по этапам из КП: дублирование заявок в
таблицу, календарь занятости домиков, автонапоминания перед заездом.

Календарь занятости в прототипе — статичный пример, данные нужно брать из того
же источника, что и брони.

## Карта

Виджет Яндекса грузится по клику (кнопка «Показать карту») — так быстрее и не
тянет чужой скрипт на каждом заходе. На боевом сайте можно вставлять сразу:

```html
<iframe src="https://yandex.ru/map-widget/v1/?ll=32.102471%2C69.785748&z=10&pt=32.102471,69.785748,pm2rdm"
        width="100%" height="340" frameborder="0"></iframe>
```

## Разбивка на страницы

Сейчас всё на одной странице. Для поиска и рекламы лучше разнести:

```
/                  главная (то, что в прототипе, но короче)
/rybachiy          база: домики с галереями, инфраструктура, как добраться
/rybachiy/tury     туры по полуострову, дальше по странице на тур
/teriberka         Териберка + сезоны
/teriberka/zima    и так на каждый сезон
/transport         вездеход и заброска
/contacts
```

Форма заявки — сквозная, один компонент на всех страницах.
